# Coordant 0.2.29

Review has a new layout, and repeated controls have more consistent spacing.

- Command results, menu options, file rows and action buttons now have even gaps. Keyboard navigation keeps the selected command visible, with space around the scrolling list.
- Review has a clear header, a separate scope and branch row, and fixed Commit, Pull and Push / PR actions. Files and Changes align side by side or stack in narrower panels.
- Diff sections separate filenames from folder paths and use the selected theme's neutral borders and backgrounds. File filters, staging controls and metadata have more room.
- Compact layouts keep actions reachable and omit a redundant Changes heading. Shared file and review helper text is easier to read.

Verified with all 19 themes, dark/light layouts down to a 320 px sidebar, keyboard navigation, filtered staging and unstaging, branch comparison and file previews. macOS package checks also cover existing chat, agent, browser, provider and updater workflows.
