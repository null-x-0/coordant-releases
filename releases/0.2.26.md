# Coordant 0.2.26

Files, file previews, Review, agent threads, tasks, and browser navigation now share a 52-pixel content header. Each uses the same quiet upper divider and stronger lower border. Files keeps the working folder visible as secondary context.

Review places the scope and change totals in its header. Review options contains collapse and visibility controls alongside the layout choices. Commit, Pull, and Push / PR use compact icons with tooltips in narrow sidebars, leaving room for the branch name; wider sidebars retain their labels.

Agent thread rows have a 16-pixel gap, matching the space below the thread header.

Verified with light and dark themes, compact and expanded sidebars, thread navigation, Review controls, native browser containment, and macOS package and updater checks.
