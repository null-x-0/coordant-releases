# Coordant 0.2.15

Chat keeps its working indicator and steering controls through long responses and Terminal/Chat switches. Loading earlier messages now expands the history read and keeps your scroll position. Error messages use a small status dot, the Steer control uses an icon, and sidebar session spacing is consistent. The Agents panel now focuses on message threads; newly spawned agents follow the provider-number naming scheme.

Answer agent questions directly in Chat through Coordant's shared question tool. Claude Code also supports its native question form. Answers stay attached to the conversation and running agent that asked them.

Usage adds confirmed Codex reset redemption, persistent warnings at 10%, 5% and 1% remaining, and a fixed daily allowance marker with a warning near its ceiling. The marker recalculates on the next local day. Session API reference costs appear beside tokens when every model has a known price, using the editable rates from Usage. These are estimates, not subscription charges.

The new coffee button keeps the computer awake while Coordant is open, including with the screen locked or off. It cannot prevent forced sleep or suspension when a laptop lid closes. A short first-run tour introduces Chat/Terminal switching, agent collaboration, worktrees, usage and schedules; reopen it in Settings.

Claude Code joins the supported CLIs, with installation, native sign-in, isolated additional accounts, model discovery, Chat/Terminal views, questions, exact conversation resume, token usage, schedules, agent collaboration and Git text generation. Existing native configuration and status-line commands are preserved. First-time native authentication and folder trust still happen in Terminal. Claude subscription limits appear when its native status line supplies them; unsupported provider limits remain unavailable.

Validated on macOS with native CLI/local-response fixtures, without spending inference quota or redeeming a real reset credit. Claude subscription sign-in and live subscription quotas could not be verified without an account. Windows and Linux remain unverified for this release.
