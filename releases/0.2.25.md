# Coordant 0.2.25

Pane pickers now use consistent padding and gaps. Search fields, session rows, and footer dividers share their left and right edges, with aligned icons and labels.

Tasks now uses the same single-row header as Threads. The task list's title and completion details sit below it. Thread rows have straight separators at rest and rounded backgrounds on hover or keyboard focus.

Side-by-side Review adds a divider above the file search, aligned with the first changed-file header.

Coordant tour now sits at the right of the Settings toolbar. It remains accessible while scrolling or switching Settings tabs.

Verified with light and dark themes, compact layouts, task and agent-thread checks, native providers, and macOS package and updater checks.
