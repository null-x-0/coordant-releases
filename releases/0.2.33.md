# Coordant 0.2.33

Windows can find existing CLI installations through quoted paths, standard package-manager locations, and updated Windows PATH settings without restarting Coordant.

Refresh in Accounts and models and New session now rechecks the installed CLI and native sign-in before updating the available models. This recovers accounts after installing a CLI or signing in from another terminal.

A failed sign-in launch names the missing provider instead of reporting a missing shell. Settings labels saved model profiles and unverified accounts so a stored model list does not imply a working connection.
