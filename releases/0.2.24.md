# Coordant 0.2.24

Incoming Coordant agent messages stay in Agents threads instead of appearing as user-message envelopes in regular Chat. Native conversation history and agent delivery are preserved.

The Latest button keeps its position while pressed and reliably returns to the bottom, including during a message-navigation scroll. Pane-picker rows have more breathing room and show the correct provider names.

Review options now offers stacked or side-by-side files and changes, plus the existing automatic layout. Each working folder remembers its choice. Both panes scroll independently.

The spacing around the dot between session tokens and cost now matches Usage and its percentage.

Verified with all-provider transcript fixtures, conversation and agent-thread checks, mouse and keyboard interaction checks, narrow and wide review layouts, saved preferences, native PTYs, and macOS package checks.
