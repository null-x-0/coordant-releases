Coordant 0.2.8 adds Cursor support and makes sessions easier to manage.

- Install supported CLIs from Settings, then sign in with your own account. Cursor supports native conversations, models, Chat, attachments, schedules, and agent collaboration.
- Codex model switching handles Max and Ultra correctly, including the nested reasoning menu. Model discovery refreshes correctly after account or provider changes.
- Open agent conversations in the right sidebar’s Agents tab. Messages are grouped into readable threads, and worker reports direct the coordinator to continue the remaining stages of your request.
- Click a stopped chat to resume it. Archive running chats or all chats in a project with confirmation. Select archived chats for bulk permanent deletion, also with confirmation. No project uses the same archive controls and layout.
- The X in a split session bar closes only that pane. Stop remains a separate control on every pane.
- Updates protect active work and close idle sessions before restarting. Account controls share the standard height, and the titlebar logo and wordmark share the app’s softer white. Keyboard focus uses a quiet treatment without bright outlines.

Existing users can download and restart from the version button at the bottom left. Project files and native conversation history are preserved. Cursor subscription limits are unavailable through its CLI, so the quota display stays --%.

This release uses Coordant’s consistent signing identity and is not Apple-notarized. See the [installation instructions](https://github.com/null-x-0/coordant-releases#install) for first launch on another Mac.
