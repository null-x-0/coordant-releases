# Coordant 0.2.32

Clone from GitHub now finds local GitHub connections and lets you search accessible repositories, including shared and organization projects. Choose an account without changing your global sign-in, or paste a Git/SSH address as before.

Windows and Linux builds include native terminals and installation support for all five providers. Windows launches preserve multiline prompts and Unicode paths, find native Cursor installations, and wait for CLI processes to close before cleaning up their files. Linux packages include the shared libraries needed by image attachments.

Coordant agents no longer receive usage commands, quota details, or instructions for resetting limits. Coordant still considers usage when assigning work across accounts. Usage and reset controls remain available to the user.

Cursor connections now explicitly carry the current Coordant session into the native CLI’s MCP subprocess, restoring its browser, agent, and task tools. Closing a session revokes and removes that connection.
