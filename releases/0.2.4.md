Simpler attachments and session setup.

- One paperclip opens the macOS picker directly for files, images, and folders, including mixed selections.
- Attachments in the composer share one height, including image previews.
- Message navigation keeps its expanding markers without a gray hover box.
- File and folder chips match the height of a single-line message. Image thumbnails are twice that height.
- New session below Schedules lets you choose a project or No project. Buttons inside project groups keep their project target.

[Download for Apple silicon](https://github.com/null-x-0/coordant-releases/releases/download/v0.2.4/Coordant-0.2.4-mac-arm64.dmg) · [Download for Intel](https://github.com/null-x-0/coordant-releases/releases/download/v0.2.4/Coordant-0.2.4-mac-x64.dmg)

Existing users can choose Check for updates, download, and restart inside Coordant. Project files and native conversation history are preserved.

This release uses Coordant's consistent signing identity and is not Apple-notarized. See the [installation instructions](https://github.com/null-x-0/coordant-releases#install) for first launch on another Mac.
