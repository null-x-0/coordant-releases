# Coordant 0.2.34

Fixes Codex replies and working indicators missing from Chat on Windows while the terminal conversation continues normally. Coordant now invokes the native session hook through PowerShell and forwards its conversation identity as UTF-8, including installation paths containing spaces or non-ASCII characters.

Chat also waits for Codex to finish loading before submitting the first message, preventing it from being left as an unsent terminal draft.

Start a new Codex session after updating to use the corrected connection. Your native CLI history stays in place.
