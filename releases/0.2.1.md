The first shared release of Coordant for macOS.

- Use your Codex and Grok accounts in one workspace, with chat and terminal views.
- Coordinate agents, arrange split sessions, and keep browser and Git tools alongside your work.
- Manage schedules, provider accounts, and usage from the app.
- Download future updates inside Coordant without a GitHub sign-in.
- Native macOS window controls and light/dark app icons.

**[Download for Apple silicon](https://github.com/null-x-0/coordant-releases/releases/download/v0.2.1/Coordant-0.2.1-mac-arm64.dmg)** · **[Download for Intel](https://github.com/null-x-0/coordant-releases/releases/download/v0.2.1/Coordant-0.2.1-mac-x64.dmg)**

Open the DMG and drag Coordant into Applications. The ZIP and YAML files below support in-app updates.

**First launch:** This release is signed with a consistent Coordant identity but is not Apple-notarized. If macOS blocks opening it, follow [Apple's first-launch approval instructions](https://support.apple.com/guide/mac-help/mh40616/mac). No GitHub account is needed; agent providers use your own sign-ins.
