# Coordant 0.2.20

Models and costs now shows month-to-date token totals and API reference estimates from the same recorded usage. The month follows your selected time zone. Work in an older conversation still counts when its usage happened this month, and estimates no longer depend on a subscription reset period being available. Edited rates continue to take precedence; missing prices and incomplete history remain explicit. Per-session totals still cover the whole conversation.

Claude now uses the original Claude Spark geometry from Anthropic's official press kit, rendered in the selected theme's foreground color. Hovering or keyboard-focusing a session dropdown brightens its text without adding a background box; the focused pane keeps its existing header treatment.

Agent account responses no longer include available reset credits. Native quota percentages, reset times and account balancing remain available for orchestration. Reset redemption remains a confirmed user action in Usage; Coordant does not inject reset commands into agent instructions.

Error dots now align with the first line of their message in Chat, browser errors, file previews, Git actions and dialogs. Failed-send panels mark the failure explanation below the original message and attachments. Opening an agent thread replaces the Threads heading with its participant names and back button in the same row.

Validated with calendar-month and time-zone boundary tests, dated usage from all five providers, duplicate/fork handling, native OpenCode queries, editable-price UI checks, and macOS PTY checks. Live subscription charges are not inferred from token counts.
