# Coordant 0.2.21

The embedded browser stays inside its sidebar and above the bottom status bar. Native view placement now accounts for app zoom, clips overflowing content, and rejects outdated measurements after a window resize. Expanding the sidebar, opening diagnostics, switching tabs, and taking page captures preserve the same live page.

Load earlier messages now has a consistent gap below the revealed chat toolbar, including narrow panes. Revealing the toolbar does not shift the conversation.

Verified with native browser bounds checks, chat history loading and spacing checks, theme validation, and macOS PTY checks using disposable application data.
