Coordant 0.2.12 fixes a startup error affecting saved Cursor sessions, including after an update.

The app could save a Cursor session but reject its provider when reopening. The fix accepts the saved session without resetting your workspace. Projects, accounts, session names, archives, and native conversation history stay in place.

If Coordant currently shows an error mentioning `sessions` and `originKind`, close it and replace the app in Applications using the download below. Keep your existing Coordant application data. No reset or data cleanup is needed.

[Download for Apple silicon](https://github.com/null-x-0/coordant-releases/releases/download/v0.2.12/Coordant-0.2.12-mac-arm64.dmg) · [Download for Intel](https://github.com/null-x-0/coordant-releases/releases/download/v0.2.12/Coordant-0.2.12-mac-x64.dmg)

Restart checks now cover saved sessions from every supported provider, including Cursor, through both app restart and the signed updater.

This release uses Coordant's existing signing identity. See the [installation instructions](https://github.com/null-x-0/coordant-releases#install) for first launch on another Mac.
